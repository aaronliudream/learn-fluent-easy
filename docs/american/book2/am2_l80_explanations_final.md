### s5 seq4 | ans: from
“与…不同”固定用 different from。✓ different from all other buildings. ✗ than:用于比较级 -er than;✗ to / with:不与 different 搭配(美式英语固定 different from)。

### s5 seq5 | ans: easier
easy 是短词,比较级把 y 变 i 加 -er = easier,后接 than。✓ Travel today is easier than it was in 1851. ✗ easy:原级;✗ easiest:最高级;✗ more easy:短词不用 more。

### s5 seq6 | ans: more
beautiful 是长词,比较级用 more + 原级 + than。✓ more beautiful than the old one. ✗ most:最高级;✗ very / much:不构成比较级。

### s5 seq7 | ans: not as easy as
“不像…那么…”用 not as + 原级 + as，两个 as 都不能少、也不能换成 than。✓ traveling was not as easy as it is today. ✗ not so easy than:同级比较不用 than;✗ not as easier as:同级比较用原级 easy,不用比较级 easier;✗ not easy so as:词序错。

### s5 seq8 | ans: as big as
“和…一样…”用 as + 原级 + as。✓ as big as a football field. ✗ so big as:肯定句同级用 as…as,不用 so…as;✗ as bigger as:同级用原级 big,不用比较级;✗ as big than:同级用 as，不用 than。

### s5 seq9 | ans: as wonderful as
“和…一样…”用 as + 原级 + as。✓ as wonderful as the steam hammer. ✗ so wonderful than / as more wonderful as / as wonderful than:都不是正确的同级比较结构(同级用 as…as + 原级)。
