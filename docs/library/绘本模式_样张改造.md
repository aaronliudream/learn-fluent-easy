## 3. 数据结构

⚠️ 指令书里的 `reading_book_chunks` **本库不存在**(PGRST205),正文原子表是 `library_sentences`。
详见 `DECISIONS.md`「绘本模式:chunk 表 = library_sentences」。两列加在 `library_sentences`:

- `page_index int` —— 绘本页号(1-based),**同一页的多句共用同一个号**;
- `image_url text` —— 该页配图,存**桶内相对路径**;填绝对 `http(s)` URL 也认。

分页口径(`buildPages()`):

1. 本章任一句有 `page_index` → 按它分组;
2. 全空(SQL 没跑 / 没配页)→ **回退按 `para_idx` 一段一页**,不报错;
3. 某句 `page_index` 为空 → 并入上一页,不新起空页。

页图取值顺序:本页任一句的 `image_url` → **页图兜底表** `PICTURE_BOOK_PAGE_IMAGES` →
`library_illustrations` 中 `position = 页序号` 的图 →(仅第 1 页)`position = 0` 的章首图 →
都没有则显示骨架占位。图片 404 也走占位,不出破图。

> 兜底表是为「图已传桶、但 SQL 还没跑」这段窗口准备的:不跑 SQL 也能看到完整 3 页绘本。
> SQL 跑完后 DB 的 `image_url` 自动接管(优先级更高),兜底表那几行就可以删。

## 5. 交互要点(为什么这么定)

- **点画面不翻页**:点击留给单词收藏(`TappableLine`),否则会误收藏。翻页 = 左右箭头 / 页码圆点 / 左右滑
  (滑动判定:横向位移 ≥ 50px 且纵向 ≤ 40px;纯点击位移 ≈ 0 → 永不触发)。
- **文字卡浮在图片内**:左右各留 10px、底 10px,最高 = 图高 50%,超出**卡内滚动**(`overscroll-contain`),
  所以三种阅读模式(英文 / 中英 / 中文)切换时**图片高度恒定**,不跳版。
- **播放**:本页播放键 → 复用 `playChapterFrom(start, end)`,读完本页停;顶部「朗读本章」→ 从第 1 页顺序播,
  句子推进跨过页边界时**自动翻到下一页**(靠 `current` 落在哪一页反推),最后一页播完停住,不循环不跳章。
  翻页(手动)先 `stopAll()` → 立即打断上一页音频。iOS 首点出声沿用现有 `unlockAudioSync`(在 `playChapterFrom` 里)。
- **TTS 一行没碰**:音频全部复用现有链路(有 `audio_url` 用预生成,没有则实时合成)。伊索 ch1 当前 11 句都无
  `audio_url` → 走实时合成。
