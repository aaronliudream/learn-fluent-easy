## 入库与自查说明

1. 共 48 题（8×6），考点 14 个（L13 2 + L14 3 + L15 2 + L16 3 + L17 2 + L18 2），掌握度按考点：该考点题答对 2 次 = 考点掌握。
2. transform 题 answer_text 判定：忽略大小写与末尾标点差异，其余需全匹配。L15 第 5 题接受 "Have some water, please." 与 "Please have some water." 两种答案。
3. 语义对应铁律自查通过：每题答案唯一，干扰项均为语法或语义确定错误。
4. 与关10 通关题题干零重复（考点相同、句子素材不同，已逐题核对；如关5 复数题用 bike/street 素材，关10 用 truck/lamp 素材）。
