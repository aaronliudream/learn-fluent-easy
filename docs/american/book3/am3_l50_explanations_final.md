# AM3 L50 逐题解释(定稿·原创承载·不定式/强调句 It was…that/形容词·分词状语/短语动词/so that·if 条件·新年的决心) · 供 gen-book3-seed.mjs loadExp 合并

### s5 seq1 | ans: to get
resolve to do sth,“决心做某事”,后接不定式。✓ We resolve to get up earlier. ✗ getting / get / got:resolve 后用不定式 to get。

### s5 seq2 | ans: to do
两个并列的目标都用不定式;后面是 to read,前面也要 to do。✓ to do exercises and to read more. ✗ doing / do / did:与 to read 并列用 to do。

### s5 seq3 | ans: to creep
manage to do sth,“设法做成”,后接不定式。✓ I managed to creep down. ✗ creeping / creep / crept:manage 后用不定式 to creep。

### s5 seq4 | ans: that
强调句 It was + 被强调部分 + that;被强调的不是人,连接词用 that。✓ It was this that betrayed me. ✗ what / which it / and:强调句连接词用 that。

### s5 seq5 | ans: that
强调时间也用 It was … that …,不用 when。✓ It was on January second that I began. ✗ when / which / what:强调句一律用 that。

### s5 seq6 | ans: It
强调句句首用形式词 It:It was + 被强调部分 + that …。✓ It was my exhaustion that gave me away. ✗ This / That / There:强调句句首用 It。

### s5 seq7 | ans: out
carry out,“实行、执行”;固定副词 out。✓ never find time to carry them out. ✗ off / on / up:carry 搭配 out。

### s5 seq8 | ans: into
slip back into,“滑回到、故态复萌”;固定介词 into。✓ slipped back into my old habit. ✗ on / at / for:slip back 搭配 into。

### s5 seq9 | ans: off
fend off,“挡回、避开”;固定副词 off。✓ fended off the taunts. ✗ in / up / over:fend 搭配 off。

### s5 seq10 | ans: Aware
形容词短语作状语,逻辑主语是主句的 I;Aware of …,“意识到…”。✓ Aware of these pitfalls, I kept … ✗ Awaring / Awared(aware 无这些形式)/ To aware。

### s5 seq11 | ans: Resisting
现在分词短语作状语,主动“抵制…”;逻辑主语是 I。✓ Resisting the effect of TV, I sat … ✗ Resisted / Resist / To resist:作状语的主动分词用 -ing。

### s5 seq12 | ans: Feeling
现在分词短语作状语,主动“感到…”;逻辑主语是 I。✓ Feeling cold and lonely, I went downstairs. ✗ Felt / Feel / To feel:主动伴随用 -ing。

### s5 seq13 | ans: so
so that,“结果、以至于”;此处填 so,与后面的 that 搭配。✓ so that we look even more foolish. ✗ such(接名词)/ in / by:与 that 构成结果状语的是 so。

### s5 seq14 | ans: If
条件状语从句“如果…就…”用 If 引导。✓ If I spent less time …, I would read more. ✗ Unless(除非)/ So / Though(虽然)。

### s5 seq15 | ans: would
与现在/将来相反或假设的条件,主句用 would + 动词原形。✓ If I had more time, I would read the whole book. ✗ will(此处是虚拟)/ did / am。

### s5 seq16 | ans: inveterate

热情渐渐减弱、变小是 wane。✓ my enthusiasm waned. ✗ grows 增长(相反);✗ explodes 爆发;✗ freezes 冻结——都不对。
