### s5 seq1 | ans: Not
部分否定 Not all …，“并非所有…都…”。✓ Not all sounds serve as language. ✗ No / None / Never:部分否定用 Not all。

### s5 seq2 | ans: every
部分否定 not every …，“并非每一…都…”。✓ Not every bat uses echolocation the same way. ✗ all(与 not 连用意思重复)/ some / any:与 not 构成部分否定用 every。

### s5 seq3 | ans: are
部分否定 + 被动;主语 fish 复数,be 用 are。✓ Not all fish are detected by their echo. ✗ is(单数)/ was(时态)/ has:复数被动用 are。

### s5 seq4 | ans: was
so + 倒装:So + be 动词 + 主语;叙述过去用 was。✓ So was born the apparatus. ✗ is(时态)/ has / did:此处用 was。

### s5 seq5 | ans: that
so … that …,“如此…以至于”;引导结果用 that。✓ So loud was the squeak that it echoed. ✗ as / which / than:结果连词用 that。

### s5 seq6 | ans: fast
so + 副词 + 倒装:So fast does the bat fly that…;填副词 fast。✓ So fast does the bat fly… ✗ faster / fastest / more fast:此处用原级副词 fast。

### s5 seq7 | ans: By
by + 动名词表方式,“通过做…”。✓ By measuring the interval… ✗ With / On / In:表方式“通过”用 By。

### s5 seq8 | ans: be
情态被动 can + be + 过去分词;填中间的 be。✓ the sea bottom can be located. ✗ is / been / being:can 后用原形 be + 过去分词。

### s5 seq9 | ans: calculated

### s5 seq10 | ans: on

### s5 seq11 | ans: of

### s5 seq12 | ans: in

### s5 seq13 | ans: not
not only … but …,“不仅…而且…”;前半用 not。✓ not only to locate a shoal but to name the fish. ✗ no / never / none:此结构前半用 not。

### s5 seq14 | ans: varying

### s5 seq15 | ans: do
