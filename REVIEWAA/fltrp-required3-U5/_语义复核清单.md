### u5.01 would do(从过去某点看的将来 / 转述的将来)
- Before the climb, Mallory promised his wife that he ____ home safely.
  **would come✓** / will come / came / comes
  考点:would do(从过去某点看的将来 / 转述的将来) ｜ 解析:主句 promised 是过去时,'平安回家'当时还没发生 → 过去将来 would come;will 视角错,一般过去尚未发生。
- The captain announced that the ship ____ port at dawn the next day.
  will leave / **would leave✓** / left / leaves
  考点:would do(从过去某点看的将来 / 转述的将来) ｜ 解析:announced 过去 + the next day 将来标志 → would leave。
- None of the sailors knew that those days ____ their last together.
  will be / are / **would be✓** / have been
  考点:would do(从过去某点看的将来 / 转述的将来) ｜ 解析:knew 过去、当时并不知道结局 → 从过去看的将来 would be。

  will return / returned / returns / **would return✓**
  考点:would do(从过去某点看的将来 / 转述的将来) ｜ 解析:said 过去 + again one day 将来 → would return。
