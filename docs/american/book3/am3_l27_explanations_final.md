# AM3 L27 逐题解释(定稿·原创承载·It is said that/不可数名词/there be/目的状语/被动不定式·不卖也不买) · 供 gen-book3-seed.mjs loadExp 合并

### s5 seq1 | ans: said
“据说”用被动 It is said that…,said 是 say 的过去分词。✓ It is said that everyone… ✗ saying / say / to say:这里用过去分词 said。

### s5 seq2 | ans: is
“据说某人…”用 sb is said to do,这里用 is。✓ The wanderer is said to enjoy freedom. ✗ has / does / being:被动报道用 is said。

### s5 seq3 | ans: to lead
sb is said + 不定式(to do)。✓ He is said to lead a simple life. ✗ leading / lead / led:said 后接 to do。

### s5 seq4 | ans: knowledge
knowledge 是不可数名词,不加 s、前面不加 a。✓ sell knowledge. ✗ knowledges / a knowledge / knowledge's:不可数,不变复数。

### s5 seq5 | ans: advice
advice 是不可数名词,不加 s、不用 an。✓ some useful advice. ✗ advices / an advice / advice's:不可数,用 some advice。

### s5 seq6 | ans: was
news 是不可数名词,作主语时动词用单数。✓ The news was good. ✗ were / are / have been:news 用单数动词。

### s5 seq7 | ans: are
there be + 复数(times)用 there are。✓ There are times when… ✗ is / has / have:后接复数名词用 are。

### s5 seq8 | ans: were
一般过去、后接复数(stores)用 there were。✓ there were no stores. ✗ was / are / has been:过去 + 复数用 were。

### s5 seq9 | ans: has
现在完成、后接单数(a great change)用 there has been。✓ There has been a great change. ✗ have / is / was:完成时单数用 has been。

### s5 seq10 | ans: so that
目的“以便”,后面接一个带主语和动词的从句,用 so that。✓ so that he can buy food. ✗ so as / in order（后接 to do）/ because（表原因）。

### s5 seq11 | ans: in order to
目的“为了”,后面接动词原形,用 in order to。✓ in order to move easily. ✗ so that（接从句）/ for to / because of。

### s5 seq12 | ans: so as not to
目的的否定“以免”,后面接动词原形,用 so as not to。✓ so as not to wake the town. ✗ so as to not / for not to / not to so as:固定语序是 so as not to。

### s5 seq13 | ans: to be paid
“技能被花钱买”用被动不定式 to be paid (for)。✓ skills have to be paid for. ✗ to pay / paying / paid:被动用 to be paid。

### s5 seq14 | ans: which
指物的关系代词用 which(或 that)。✓ the freedom which few people taste. ✗ who（指人）/ whose / when:指物用 which。

### s5 seq15 | ans: whom
“介词 + 关系代词”指人时用 whom。✓ the friend with whom he travels. ✗ which（指物）/ who（作宾语时介词后用 whom）/ whose:with 后用 whom。

### s5 seq17 | ans: contempt
认为某人一文不值的强烈感觉是 contempt(蔑视)。✓ speak with contempt. ✗ respect 尊敬;✗ gratitude 感激;✗ joy 喜悦——都不对。
