# AM3 L12 逐题解释(定稿·原创承载·条件句 if + wish/if only 虚拟愿望·荒岛生活) · 供 gen-book3-seed.mjs loadExp 合并

### s5 seq1 | ans: will cancel
真实条件:很可能发生,if 从句用一般现在时(rains),主句用将来时 will do。✓ If it rains, we will cancel the trip. ✗ cancel:主句要用将来时;✗ would cancel:那是虚拟;✗ cancelled:时态不对。

### s5 seq2 | ans: will be
真实条件的主句用将来时:will be hungry。✓ You will be hungry if you don't catch any fish. ✗ would be:那是虚拟;✗ are being / were:时态或语气不对。

### s5 seq3 | ans: were
与现在事实相反的虚拟里,be 动词一律用 were,不分人称:If I were you…。✓ If I were you, I would stay longer. ✗ am / was:虚拟里固定用 were;✗ will be:那是真实条件。

### s5 seq4 | ans: had
与现在事实相反的虚拟,if 从句用过去时:If they had a gun now…(其实现在没有)。✓ If they had a spear gun now, they could catch fish. ✗ have:那是真实/现在;✗ will have / has:语气或人称不对。

### s5 seq5 | ans: had
与现在相反的虚拟,if 从句用过去时 had(其实岛上没淡水)。✓ If the island had fresh water, life would be easier. ✗ has / will have:不是虚拟;✗ would have:would 用在主句,不用在 if 从句。

### s5 seq6 | ans: would have stayed
与过去事实相反的虚拟,主句用 would have + 过去分词。✓ If the boat had not sunk, they would have stayed on it. ✗ stayed / will stay / stay:配不出“与过去相反”的虚拟。

### s5 seq7 | ans: had not
与过去相反的虚拟,if 从句用过去完成(had done / had not done)。✓ If that tanker had not come along… ✗ did not / does not / would not:配不出对过去的虚拟。

### s5 seq8 | ans: might have starved
与过去相反的虚拟,主句用 might/would have + 过去分词。✓ They might have starved if they had not brought the gun. ✗ starved / would starve / starve:配不出对过去的虚拟。

### s5 seq9 | ans: knew

### s5 seq10 | ans: had
