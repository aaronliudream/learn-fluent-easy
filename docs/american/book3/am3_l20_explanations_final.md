### s5 seq1 | ans: happened
“碰巧正在做某事”用 happen to be doing,过去用 happened。✓ Latham happened to be flying over the sea. ✗ happen / happens / happening:这里要用过去式 happened。

### s5 seq2 | ans: happened
“It happened that…”表示“碰巧……”,过去用 happened。✓ It happened that both pilots reached the coast. ✗ happen / happens / happening:要用 happened。

### s5 seq3 | ans: happen
“if you happen to…”表示“你要是碰巧……”,和 if 连用用原形 happen。✓ If you happen to see the plane… ✗ happened / happens / happening:这里用原形 happen。

### s5 seq4 | ans: had

### s5 seq5 | ans: had

### s5 seq6 | ans: did

### s5 seq10 | ans: were supposed

### s5 seq11 | ans: supposed

### s5 seq12 | ans: woke

### s5 seq13 | ans: had better

### s5 seq14 | ans: save up

### s5 seq15 | ans: to be
