### s5 seq1 | ans: higher
the + 比较级, the + 比较级,“越…越…”;后半也要 the + 比较级,high 的比较级是 higher。✓ the bigger …, the higher … ✗ high(缺比较级)/ highest(最高级)/ more high(错误变形)。

### s5 seq2 | ans: more
前半同样用 the + 比较级;much 的比较级是 more。✓ The more you practice, … ✗ most(最高级)/ much(原级)/ many(修饰可数,此处不当)。

### s5 seq3 | ans: harder
后半 the + 比较级;hard 的比较级是 harder。✓ the harder it was to lift. ✗ hard(原级)/ hardest(最高级)/ more hard(错误变形)。

### s5 seq4 | ans: so
so + 形容词/副词 + that,表“如此…以至于”;smooth 是形容词,前用 so。✓ so smooth that … ✗ such(接名词)/ very(不接 that 结果)/ too(too…to 结构不同)。

### s5 seq5 | ans: that
such a + 名词 + that + 结果;引导结果的连词用 that。✓ such a heavy pan that four men … ✗ so(此处已用 such)/ as / which:引导结果用 that。

### s5 seq6 | ans: that
so + 形容词 + that + 结果;引导结果分句用 that。✓ so strong that it nearly … ✗ as / than / so:结果分句用 that。

### s5 seq7 | ans: Shivering
现在分词短语放句首作状语,说明主语 teenagers 的伴随状态“冻得发抖”;主语主动,用现在分词。✓ Shivering in their wet clothes, the teenagers … ✗ Shiver / Shivered / To shiver:作状语的主动分词用 -ing。

### s5 seq8 | ans: Working
同理,现在分词短语作状语“以极快速度干”;主语 men 主动,用 Working。✓ Working at tremendous speed, the men … ✗ Work / Worked / To work:主动伴随用 -ing。

### s5 seq9 | ans: searching
现在分词表伴随动作“一边找”;与主语 men 主动同时,用 searching。✓ The men dove in, searching for the pan. ✗ searched / to search / search:伴随用 -ing。

### s5 seq10 | ans: finding

### s5 seq11 | ans: proved

### s5 seq12 | ans: to be
