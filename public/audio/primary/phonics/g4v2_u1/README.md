# G4V2 Unit 1 phonics audio

Place kid-voice MP3 files here (one per word). The phonics page loads these paths first; if a file is missing, playback falls back to CDN kid TTS.

Expected files:

- `water.mp3`
- `tiger.mp3`
- `sister.mp3`
- `dinner.mp3`
- `computer.mp3`
- `ruler.mp3`

Optional (stage 2 discrimination words):

- `teacher.mp3`, `farmer.mp3`, `number.mp3`, `mother.mp3`, `winter.mp3`

Record at a steady pace, emphasizing the unstressed **er** /ə(r)/ at the end of each word.
