# AM4 L20 逐题解释(定稿·原创承载·how从句作主语/情态+have done/It is said that/though·whenever/as…as·蛇毒) · 供 gen-book4-seed.mjs loadExp 合并

### s5 seq1 | ans: How
疑问词从句作全句开头,‘…是如何’用 How;整句谓语用 is。✓ How snakes came to make venom is a mystery. ✗ That(不问方式)/ Which / What:表‘如何’用 How。

### s5 seq2 | ans: What
名词从句作全句开头,‘什么…’用 What(在从句中充当成分)。✓ What makes the venom so deadly is not known. ✗ That / Which / Whether:表‘什么’用 What。

### s5 seq3 | ans: Why
疑问词从句作全句开头,‘为什么’用 Why。✓ Why Nature chose only snakes remains unexplained. ✗ That / Which / How:表‘为什么’用 Why。

### s5 seq4 | ans: can
情态词 + have + 过去分词表对过去推测;‘不大可能曾…’用 can hardly have done。✓ Survival can hardly have forced the change. ✗ must / need / dare:此处用 can。

### s5 seq5 | ans: have
must + have + 过去分词,对过去的肯定推测;中间的助动词是 have。✓ must have developed the poison slowly. ✗ has / had / be:情态词后一律用 have。

### s5 seq6 | ans: could
情态词 + have + 过去分词;‘不可能曾…’用 could not have done(= couldn't have)。✓ Poison could not have appeared overnight. ✗ would / should / may:表‘不可能曾’用 could not have。

### s5 seq7 | ans: said
It is said that …,‘据说、有人说’;say 的过去分词 said。✓ It is often said that the nerve poison is primitive. ✗ saying / say / to say:被动用过去分词 said。

### s5 seq8 | ans: is
It ___ said that …:被动结构用 be 动词 is。✓ It is said that the blood poison came later. ✗ are / has / does:此结构用 is + said。

### s5 seq9 | ans: that
It is believed + that 从句,‘人们相信…’;引出内容用 that。✓ It is believed that venom evolved from saliva. ✗ what / which / whether:引出陈述内容用 that。

### s5 seq10 | ans: though
‘尽管、虽然’引导让步,用 though。✓ Venom helps a hunter, though it may harm its own kind. ✗ because / once / unless:表让步用 though。

### s5 seq11 | ans: Whenever
‘每当、无论何时’用 Whenever。✓ Whenever two venomous hunters fight, the poison cuts both ways. ✗ Because / Unless / Although:表‘每当’用 Whenever。

### s5 seq12 | ans: though
‘尽管、虽然’引导让步,用 though。✓ The poison is deadly, though it evolved for hunting. ✗ because / once / unless:表让步用 though。

### s5 seq13 | ans: deadly
as + 形容词 + as:同级比较;填形容词 deadly。✓ One venom is as deadly as the other. ✗ deadlier(比较级)/ deadliest(最高级)/ death(名词):as…as 中间用原级形容词。

### s5 seq14 | ans: quickly
as + 副词 + as:修饰动词 strikes 用副词 quickly。✓ A cobra strikes as quickly as any viper. ✗ quick(形容词)/ quicker / quickest:此处用副词原级 quickly。

### s5 seq15 | ans: fast
as + 副词 + as:fast 作副词原级。✓ works as fast on a rat as on a mouse. ✗ faster / fastest / more fast:as…as 中间用原级 fast。
