# AM4 L5 逐题解释(定稿·原创承载·强调句/as if+were/would have done+被动不定式/动名词·青年) · 供 gen-book4-seed.mjs loadExp 合并

### s5 seq1 | ans: who
强调句 It is + 被强调的 older people + who…;被强调的是人,用 who。✓ It is older people who create it. ✗ which(指物)/ what / whose:强调人用 who。

### s5 seq2 | ans: was
强调句 It + be + …；此处叙述过去,be 用 was。✓ It was the older generation that created… ✗ is(时态不符)/ has / did:过去用 was。

### s5 seq3 | ans: that
强调句,被强调的是物 identity,连接词用 that。✓ It is identity that the young search for. ✗ who(指人)/ what / whose:强调物用 that。

### s5 seq4 | ans: were
as if + 与现在相反的虚拟,be 一律用 were。✓ as if they were cosmic beings. ✗ was / are / be:虚拟里 be 用 were。

### s5 seq5 | ans: were
as if + 虚拟,即使主语 age 是单数,be 也用 were。✓ as if age were a reason for respect. ✗ is / was / being:虚拟用 were。

### s5 seq6 | ans: had
as if + 虚拟,实义动词用过去式;have → had。✓ as if they had nothing to fear. ✗ have / has / having:虚拟用过去式 had。

### s5 seq7 | ans: would
与过去相反的虚拟,主句用 would + have + 过去分词。✓ I would have been pleased. ✗ will / can / must:主句用 would。

### s5 seq8 | ans: to
被动不定式 to be + 过去分词;填不定式符号 to。✓ delighted to be thought so interesting. ✗ for / of / that:此处用 to be thought。

### s5 seq9 | ans: be
被动不定式 to + be + 过去分词;填中间的 be。✓ glad to be regarded as a problem. ✗ being / been / was:不定式里用原形 be。

### s5 seq10 | ans: Being
动名词作主语,主动“成为…”。✓ Being a problem gives a person identity. ✗ Been / Be / To being:作主语用动名词 Being。

### s5 seq11 | ans: devotion
feel no devotion to sth,“对…没有热爱/迷恋”;此处填名词 devotion。✓ feel no devotion to material things. ✗ devote(动词)/ devoted / devoting:此处需名词 devotion。

### s5 seq12 | ans: loving
介词 in 后用动名词;love → loving。✓ interested in loving comfort above all. ✗ love / loved / to love:介词后用 -ing。

### s5 seq13 | ans: Let
祈使句“让我们…”用 Let us + 动词原形。✓ Let us get down to fundamentals. ✗ Make / Have / Do:此句型用 Let。

### s5 seq14 | ans: before
方位介词对比:未来在“前面”用 before(过去在“后面”用 behind)。✓ a glorious future before him. ✗ after / behind / under:“在…前面”用 before。

### s5 seq15 | ans: leave
take leave to do,“冒昧地做…”;固定用名词 leave。✓ I take leave to doubt. ✗ place / part / care:固定搭配是 take leave to do。

### s5 seq16 | ans: dreary
沉闷、乏味、令人厌倦的是 dreary。✓ no dreary commitment. ✗ cheerful 愉快;✗ exciting 令人兴奋;✗ bright 明亮——都不对。

### s5 seq17 | ans: conceited
过于自以为是的是 conceited。✓ a young person may be conceited. ✗ modest 谦虚;✗ shy 害羞;✗ kind 善良——都不对。

被用滥了、毫无新意的说法是 cliche。✓ the tired cliches about respect. ✗ poem 诗;✗ secret 秘密;✗ promise 承诺——都不对。
