# AM3 L25 逐题解释(定稿·原创承载·be used to 三种/a great deal of/on·in 搭配/have sth done·卡蒂萨克号) · 供 gen-book3-seed.mjs loadExp 合并

### s5 seq1 | ans: carry
be used to do sth = “被用来做某事”,to 后面接动词原形。✓ were used to carry tea. ✗ carrying(be used to doing 是“习惯于”)/ carried / carries:被用来做用原形 carry。

### s5 seq2 | ans: used to
“过去常常做某事(现在不这样了)”用 used to + 动词原形。✓ sailors used to sing. ✗ are used to / were used to(“习惯于/被用来”)/ use to:过去习惯用 used to。

### s5 seq3 | ans: sailing
be used to doing = “习惯于做某事”,to 后面接 -ing。✓ is used to sailing in rough seas. ✗ sail / sailed / sails:“习惯于”后接 -ing。

### s5 seq4 | ans: deal
a great deal of + 不可数名词(luck)。✓ a great deal of bad luck. ✗ many(接可数)/ number / few:不可数用 a great deal of。

### s5 seq5 | ans: many
a great many + 可数名词复数(ships)。✓ a great many ships. ✗ deal / deal of(接不可数)/ amount:可数用 a great many。

### s5 seq6 | ans: of
a lot of + 名词,固定搭配用 of。✓ a lot of tea and wool. ✗ in / with / for:a lot 后接 of。

### s5 seq7 | ans: on
“着火”固定搭配用 on fire。✓ almost on fire. ✗ in / at / with:固定说 on fire。

### s5 seq8 | ans: on
“步行”固定搭配用 on foot。✓ reached the port on foot. ✗ in / by / at:固定说 on foot(注意不是 by foot)。

### s5 seq9 | ans: in
“匆忙”固定搭配用 in a hurry。✓ in a hurry to fix the rudder. ✗ on / at / with:固定说 in a hurry。

### s5 seq10 | ans: fitted
have sth done“请人把某事做好”,done 用过去分词。✓ have a new rudder fitted. ✗ fit / fitting / to fit:have + 名词后用过去分词 fitted。

### s5 seq11 | ans: repaired
have sth done,用过去分词。✓ had the broken mast repaired. ✗ repair / repairing / to repair:用过去分词 repaired。

### s5 seq12 | ans: checked
have sth done,用过去分词。✓ have your compass checked. ✗ check / checking / to check:用过去分词 checked。

### s5 seq13 | ans: its
“它的”用物主词 its(不带撇号)。✓ the last of its kind. ✗ it's(= it is)/ its' / it is:表所属用 its。

### s5 seq14 | ans: too
“太…以致不好”用 too。✓ if she went too fast. ✗ very(只表程度,不含“过头”)/ so / much:含“过头”的负面结果用 too。

### s5 seq15 | ans: beat
“击败对手/某人”用 beat sb。✓ beat the Cutty Sark. ✗ win(赢的是比赛,不是对手)/ won(时态)/ defeat to:打败某人用 beat。

### s5 seq16 | ans: rudder
船尾用来控制方向的扁板是 rudder(舵)。✓ her rudder was torn away. ✗ anchor 锚;✗ sail 帆;✗ deck 甲板——都不对。

### s5 seq17 | ans: vessel
大船也叫 vessel(轮船、大木船)。✓ sailing vessels. ✗ wagon 货车;✗ carriage 马车;✗ sled 雪橇——都不对。

### s5 seq18 | ans: temporary
只用一小段时间的是 temporary(临时的)。✓ a temporary rudder. ✗ permanent 永久;✗ ancient 古老;✗ golden 金色——都不对。
