# 单元制作必做清单(每个单元一次到位)

> 高中(及通用)单元生产的**总纲**:以后每个单元(U4/U5 起)都必须全部做到。
> 配套:`docs/单元质检标准.md`(脚本硬卡判据)、`scripts/qc-unit.mjs`(自动卡)、`docs/单元真机验收清单.md`。
> Aaron 审语义 + 对照课本核考点 + 真机验收。CC 自主做完整单元,别逐步问已定的事。

## 一、内容质量铁律(QC 硬卡 + Aaron 审语义)
1. **答案分布均匀**:每维度 A/B/C/D 不全 A、不偏斜(语法 15/15/15/15、阅读/完形/听力 6/6/6/6 或 8/8/7/7)。[硬卡]
2. **无长串同位**:连续 ≥4 题同位 = FAIL(3 连是正常洗牌)。[硬卡]
3. **语法零术语**:无"选出"前缀、无"作____成分"、无"哪一项是 X 短语",全应用题。[硬卡]
4. **★语法题铁律★**:① 只考本单元语法点;② 句子让该语法点**自然成立**,不为凑考点硬套别扭动词(如 catch 进行时)。U4/U5 定从句子必须地道。[语义,Aaron 审 + 语义清单逐题列]
5. **阅读答案非照抄**:答案是对原文的概括转述,≥5 词连续子串 = FAIL。[硬卡]
6. **阅读答案覆盖全文**:多题答案依据分布在文章不同位置,不都考开头。[语义/标记]
7. **干扰项不荒谬**:不出完全脱离正文的送分干扰项(睡太多/课太短式)。[标记]
8. **完形无双解**:每空只一个答案成立、选项同词性。[语义]
9. **听力答案可溯**:答案能在 transcript 找到依据。[标记]
10. **三关不撞文章**:阅读/完形/听力三关文章互不重复(相似度 < 0.6)。[硬卡]
11. **词汇**:真词表(对课本)+ IPA 词典补音标 + 例句含目标词 + 不超纲 + 多个中文释义(多义)。[硬卡 OOV + 语义]
12. **finalReading**:短文 2-3 句独立编写(不撞阅读关)+ 2 题覆盖前后、答案转述。[硬卡 8.x]

## 二、考点必须对(对照课本)
13. **★每单元必须对照课本原文做★**:语法点/阅读课文/词汇忠实课本,别照二手信息(U3 纠正过"现在完成时→反意疑问句")。
14. **U4** = 限制性定语从句·**关系代词**(that/which/who/whose/whom),阅读 = 唐山大地震 "The Night the Earth Didn't Sleep"。
15. **U5** = 限制性定语从句·**关系副词**(when/where/why + 介词+which),阅读 = 汉字书写系统。
16. **★做完每单元给原课文对照★**:把课本相关页 + 所做考点并排发 Aaron 审。

## 三、语法小知识(每单元语法关必带)
17. 每单元语法关"进入综合测试"上方,带 **"📖 语法小知识"** 卡片(`junior_grammar_tips` 表,GrammarStage 挂载,初中高中通用、可跳过)。
18. 内容结构:**速查表(通用 table{headers,rows}) + 特殊规则重点标记 + 为什么(简短) + 高考考点 + ★考试vs真实对照★**。
19. **★考试vs真实★**:做题层答案**唯一**(保护考试、不接受多答案);语法小知识里告诉学生真实英语更灵活(Let's→shall we 考试填,口语 OK/right/yeah;aren't I 考试填,日常 right?)。**做题唯一、讲解多元**。
20. **U4/U5 造时一并写 grammar_tips**(U4 定从关系代词速查 + that/which/who 区别 + 考试vs真实;U5 定从关系副词)。源 JSON 带 `grammar_tips` 字段,随 loader 灌 `junior_grammar_tips`。

## 四、两个掌握环(核心词汇关)
21. **绿环 = 完成度** = 点开看过中文的词数 / 总词(浏览门槛,不是翻到第几组)。机制:翻卡看中文 → `recordJuniorWordViewed` 按 word_id 建行 → 绿环 = `loadUnitVocabProgress.done`。
22. **橙环 = 掌握度** = 游戏答对 2 次(consec≥2,全站统一 MASTER_STREAK)。
23. 核心词汇必须全部点开浏览才算完成(浏览门槛)。
24. 词汇答对后显示例句 + 多义。
