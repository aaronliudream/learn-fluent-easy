### s5 seq1 | ans: able
be able to 表'能够',结构 be + able + to。✓ if he is able to 如果他能。✗ can:不与 is…to 搭配;✗ could:同;✗ possible:是"可能的",不指人有能力。

### s5 seq2 | ans: able

### s5 seq3 | ans: will be able to
can 没有将来式,说将来的'能'用 will be able to。✓ I will be able to get a job 我就能找到工作。✗ can:不表将来的'能';✗ could:过去;✗ am able to:是现在。
