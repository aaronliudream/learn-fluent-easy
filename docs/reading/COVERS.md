# 图书馆封面 · 生成规格(书架视觉模板)

> 目的:让第 3 本起的封面和已定版的**绿野仙踪 / 伊索寓言**是"一家人"——同一比例、同一标题排版、同一水彩基调,整排书架才齐。
> 本规格**从这两张已审定的封面反推固化**,不是另立一套。出新书封面照此喂图,落库照此走。

| 书 | 尺寸 | 标题 | 主色 | 标志场景 |
|---|---|---|---|---|
| 绿野仙踪 `wizard-of-oz` | 800×1071 | 金色装饰衬线 `THE WONDERFUL WIZARD OF OZ`(顶部) | 翡翠绿·冷调 | 四主角走黄砖路 + 翡翠城 + 堪萨斯断崖 |

## 1. 技术规格(硬要求)

- **比例 3:4 竖版**。生图请出**精确 3:4**(如 **1200×1600** 或 900×1200)。基准两张是 0.747/0.755,和 0.75 差 ±1%,`object-cover` 裁切 <1% 肉眼看不见,所以**已有两张不必重做**;但新图按精确 3:4 出,零裁切最稳。
- **禁止**拿 16:9 的章节插图当封面(章节插图是横版,裁进 3:4 会毁构图)。
- 格式落库前我统一处理:sharp `resize({width:800}).jpeg({quality:82, mozjpeg:true})` → 传 `library-illustrations` 桶 `<book_key>/<slug>-cover.jpg` → 写进 `library_books.cover.image`。你只需给我**高清原图(≥1200 宽)**,压缩/上传/落库我来。

## 2. 标题排版(整排书架一致的关键)

- **只画英文书名**,用**金色装饰衬线**(serif + 卷草花饰),放在**顶部约上 1/3**。
- **中文书名不画在封面上**——它来自 `library_books.zh_title`,由卡片在封面**下方/旁边**以文字渲染(卡片已这么做)。这样封面保持干净的英文题、中文由元数据补,两不重复。
- 高对比 + 可读性:字缩到卡片大小(~200px 宽)仍清晰;深色描边/浅金字压在浅底上(照基准两张)。
- **安全边距**:标题及关键元素离四边留 **≥8-10%** 留白,别贴顶/贴边。理由:卡片按 3:4 不裁,但详情页 hero / 将来 banner 可能裁成别的比例,标题居中留白则任何裁切都不丢字。

## 3. 构图 / 风格基调

- **水彩童书插画**,和章节插图(Gemini 水彩)同一画风,书架才统一。
- **一组标志性角色**放画面下 2/3(该书最认得出的形象);**背景一座地标**点明出处(翡翠城 / 雅典卫城)。画面别塞满,顶部给标题留空。
- **一本一个主色调**,呼应内容:绿野仙踪=翡翠绿冷调,伊索=暖土黄橄榄绿。这个主色**同时**决定下面的降级底。
- **主题边框**(伊索的希腊回纹 + 葡萄藤)是**可选**的按书点缀,不强制;用则贴合该书文化(希腊寓言→希腊纹样)。

## 4. 降级底(`cover.c1` / `cover.c2`)

`library_books.cover` = `{c1, c2, image}`。`c1/c2` 是两个 hex,取自封面主色,作**图挂了时的渐变兜底**(前端 `coverStyle`)。基准值:

- 绿野仙踪:`c1=#10b981 c2=#065f46`(翡翠绿)
- 伊索寓言:`c1=#2f7d6e c2=#14532d`(暖绿)

新书:从封面主色调取一深一浅两个 hex。

---

## 5. 出一张新封面的清单

1. 按 §1-§3 生成**精确 3:4、≥1200 宽**的高清封面(英文金色衬线标题在顶、标志场景 + 地标、主色调统一水彩)。
2. 把原图给 CC。CC:压缩(width 800 / q82)→ 传桶 `<book_key>/<slug>-cover.jpg` → 出 SQL 写 `cover={c1,c2,image}`(c1/c2 取主色)。
3. Aaron 跑 SQL。卡片/详情页自动显新封面(有 image 时前端不再叠标题,避免和封面上的题重复)。

> 边界照旧:SQL Aaron 跑 · 不合 main · 不动 P0 · 图进 `library-illustrations` 桶。
