### s5 seq1 | ans: is
为强调形容词,so + 形容词提到句首,主语与 be 动词倒装;主语 passion 单数,用 is。✓ So great is our passion … that … ✗ does / has(不与 great 搭配作系动词)/ it is(多了 it)。

### s5 seq2 | ans: are
同理,So keen 提前引起倒装;主语 enthusiasts 复数,用 are。✓ So keen are the enthusiasts that … ✗ do / have / they are:倒装后紧跟 be 动词 are。

### s5 seq3 | ans: So
表示“如此…以至于”并引起倒装、后接 that 结果,句首用 So + 形容词。✓ So great is his pride that … ✗ Such(接名词)/ Very / Too:引起倒装 + that 的是 So。

### s5 seq4 | ans: Armed
过去分词短语作状语,表被动“被…装备好”;逻辑主语是后面的 newlyweds。✓ Armed with the right tools, newlyweds … ✗ Arming / Arm / To arm:表被动/完成用过去分词 Armed。

### s5 seq6 | ans: Taken
