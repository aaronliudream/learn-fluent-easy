### u1.02 状语从句:让步/条件/结果/时间/原因连词
- ____ he was almost paralysed with fear, Mark Twain still walked onto the stage.
  **Though✓** / Unless / So that / As soon as
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:前后是让步关系(尽管害怕仍上台)→ Though。
- Helen made steady progress ____ she could neither see nor hear.
  because / **although✓** / unless / so that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'既看不见又听不见'与'取得进步'是让步对比 → although。
- You will gradually beat stage fright ____ you keep practising in front of others.
  unless / although / **as long as✓** / because
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'只要坚持练习'是条件 → as long as;unless 表否定条件、意思相反。
- You cannot really engage your listeners ____ you speak with genuine passion.
  because / although / while / **unless✓**
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'除非满怀激情,否则吸引不了听众'→ unless(=if…not)。
- ____ the audience feels involved, they will go on listening to you.
  **As long as✓** / Unless / Although / Because
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'只要听众有参与感'是肯定条件 → As long as。
- ____ you feel nervous inside, you should still look confident on stage.
  Because / **Even if✓** / Unless / So that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'即使内心紧张也要显得自信'是让步条件 → Even if。
- He bound himself by a hard contract ____ he could not escape the lecture.
  as if / even if / **so that✓** / now that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'签合同'的目的是'无法逃避'→ so that(目的状语)。
- Speakers move around the stage ____ their presentation feels lively and energetic.
  as if / although / unless / **so that✓**
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:走动的目的是让演讲显得有活力 → so that(目的)。
- The whole hall was ____ quiet that you could have heard a pin drop.
  **so✓** / such / very / too
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'so + 形容词 + that' 引出结果状语从句 → so;such 接名词、very/too 不接 that 从句。
- It was ____ a moving moment that the entire audience sat in silence.
  so / **such✓** / very / too
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'such + a + 形容词 + 名词 + that' 引出结果 → such。
- ____ Twain glanced at the governor's wife, the whole hall burst into laughter.
  Unless / Although / **As soon as✓** / So that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'一…就…'表时间紧接 → As soon as。
- ____ she was drawing water from the well, Helen suddenly grasped the word.
  Unless / Even if / So that / **While✓**
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'在打水的同时'表正在进行的背景时间 → While。
- Helen kept confusing the two words ____ the truth finally dawned on her.
  **until✓** / unless / although / because
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'一直混淆,直到真相显现'→ until(持续到某时间点)。
- Several weeks passed ____ Helen realised that every object had its own name.
  unless / **before✓** / although / so that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'过了几周才…'→ before(…之前/才)。
- The audience kept listening closely ____ the speaker sounded truly passionate.
  although / unless / **because✓** / so that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:听众专注的原因是演讲者充满激情 → because(原因)。
- ____ public speaking can be learned, there is really no need to fear it.
  Unless / So that / As soon as / **Since✓**
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'既然演讲可以学会'是已知原因 → Since。
- ____ hard the new word seemed, Helen simply refused to give up.
  **No matter how✓** / As long as / Because / So that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'无论这个词多难'是让步 → No matter how。
- ____ Twain had spoken in public for years, he never forgot that first agony.
  Because / **Even though✓** / Unless / So that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'尽管已演讲多年'与'难忘初次煎熬'是让步 → Even though。
- ____ you win the audience's attention, holding on to it becomes much easier.
  Unless / Although / **Once✓** / So that
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'一旦赢得注意'表条件/时间 → Once;Unless/Although 逻辑不通。
- You should still sound natural ____ you are reading from a written script.
  because / so that / as soon as / **even if✓**
  考点:状语从句:让步/条件/结果/时间/原因连词 ｜ 解析:'即使在照稿念'也要自然 → even if(让步)。

### u1.03 名词性从句:主语/宾语/表语/同位语从句连接词(that/what/whether/why/how)
