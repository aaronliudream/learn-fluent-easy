## 四、三源边界裁决(L4 / L5 分工)

- **L4(已上线)**:构成 have/has+过去分词 · 状语位置 just/already/never/ever/yet · for+时间段 · gone vs been · 基础 vs 一般过去时 · vs 现在进行时。
- **L5(本课,侧重区分)**:
  - **up to now / so far / lately**(现在完成时信号词,教材 Note 2)
  - **a great many + 可数名词复数**(教材 Note 3;对比 L4 的 a great number of)
  - **since + 过去时间点/从句**(接住 L4 官方 Q5 遗漏)
  - **短暂动词完成时不接"一段时间"肯定**(同步 p44-1)
  - **现在完成时(报新闻/开头)↔ 一般过去时(追问 When 转过去)对话切换**(同步 p44-3;课文自带 Yesterday…carried[过去] vs Up to now…has sent[现完] 天然对比)
  - 不规则过去分词复现(begun/sent/bought/come)
  - 课文语言点:come up with(想主意)、from…(距离,近 away)、cover(越过)
