### s5 seq1 | ans: It
强调结构 __ is + 被强调部分 + that …;句首那个形式词是 It。✓ It is quick burial that … ✗ That / This / There:强调句句首用 It。

### s5 seq2 | ans: that
强调句被强调的是地点(in water),连接词仍用 that(不用 where)。✓ It is only in water that mud can cover a body. ✗ which / where / what:强调状语也用 that。

### s5 seq3 | ans: that
强调句被强调的是方式(by chance),连接词仍用 that(不用 how/when)。✓ It was by chance that the mammoth was preserved. ✗ which / when / what:强调状语也用 that。

### s5 seq8 | ans: destroyed
