### s5 seq1 | ans: so
interesting 是形容词,前面用 so 修饰:so interesting(如此有趣)。✓ This study is so interesting. ✗ such / such a:它们用来修饰名词,不直接接形容词;✗ much:不这么用。

### s5 seq2 | ans: so
fast 是副词,前面用 so:so fast that…(如此快以致……)。✓ The cat fell so fast that… ✗ such / such a:用于名词;✗ too:意思变“太……(不能)”。

### s5 seq3 | ans: so
strange 是形容词,用 so 修饰:so strange(如此奇怪)。✓ The idea is so strange. ✗ such / such an / a:都不直接接单个形容词。

### s5 seq4 | ans: such a
place 是单数可数名词,perfect 以辅音音开头,所以用 such a:such a perfect place(如此完美的地方)。✓ such a perfect place. ✗ so:so 后不接名词;✗ such an:元音前才用;✗ a:少了 such。

### s5 seq5 | ans: such
studies 是复数名词,复数前用 such(不加 a/an):such interesting studies。✓ such interesting studies. ✗ so:so 后不接名词;✗ such a / a:复数前不加 a。

### s5 seq6 | ans: such an
survival 是单数可数名词,amazing 以元音音开头,所以用 such an:such an amazing survival。✓ such an amazing survival. ✗ so:后不接名词;✗ such a:元音前不用 a;✗ such:单数可数要加 a/an。

### s5 seq7 | ans: so
后面直接跟形容词 lucky,用 so:so lucky(如此幸运)。✓ The cat was so lucky. ✗ such / such a / such an:它们后面要接名词,不能直接接单个形容词。

### s5 seq8 | ans: such
后面是“形容词 + 名词”a lucky escape,用 such:such a lucky escape。✓ such a lucky escape. ✗ so:so 后不接名词短语;✗ very / too:都不能像 such 那样直接接“a + 形容词 + 名词”。

### s5 seq9 | ans: so
后面直接跟副词 well,用 so:so well that…(如此好以致……)。✓ relax so well that they rarely break bones. ✗ such / such a / more:都不这么用。

### s5 seq10 | ans: the
“越……越……”结构是 the + 比较级……, the + 比较级……;第二个分句前也要用 the:the less。✓ the further… the less… ✗ a / so / more:这个固定结构里用 the。

### s5 seq11 | ans: The
“越……越……”句首也用 The + 比较级:The faster… the more…。✓ The faster the cat falls, the more it relaxes. ✗ A / So / Very:这个结构固定用 The。

### s5 seq12 | ans: The
同样,“越高……越……”句首用 The + 比较级:The higher…, the more…。✓ The higher the fall, the more air-resistance… ✗ A / Very / Most:结构固定用 The。

### s5 seq13 | ans: has
“猫有九条命”是人们普遍的说法、当成一般规律来讲,用一般现在时 has。✓ a cat has nine lives. ✗ had:那是过去;✗ is having:have 表“有”不用进行;✗ has had:这里讲普遍事实,不用现在完成。

### s5 seq14 | ans: stretch
