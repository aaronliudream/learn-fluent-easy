### s5 seq1 | ans: were
与现在相反的虚拟条件,if it were not for(要不是有…);be 一律用 were。✓ If it were not for spiders… ✗ was / is / are:虚拟里 be 用 were。

### s5 seq2 | ans: would
与现在相反的虚拟,主句用 would + 动词原形。✓ insects would devour every crop. ✗ will(非虚拟)/ can / must:主句用 would。

### s5 seq3 | ans: did
与现在相反的虚拟,if 从句用一般过去式;实义动词否定用 did not + 原形。✓ If spiders did not exist… ✗ do(非虚拟)/ will / had:此处用 did not。

### s5 seq4 | ans: more
the more … the more …,“越…越…”;第二个 the 后用比较级 more。✓ the more grateful we should be. ✗ most / much / very:递进句型两半都用比较级。

### s5 seq5 | ans: greater
比较级,与 than 呼应:great → greater。✓ greater than that of all the people. ✗ great(原级)/ greatest(最高级)/ more great(不合规则)。

### s5 seq6 | ans: more
the more + 名词 … the more …;此处 many 的比较级用 more。✓ The more insects a spider eats… ✗ most / much / many:可数名词用 more。

### s5 seq7 | ans: It
It 作形式主语,真正的主语是后面的 that 从句;固定 It has been estimated that…。✓ It has been estimated that… ✗ That / This / There:形式主语用 It。

### s5 seq8 | ans: to
it 作形式主语,真正主语是不定式;填不定式符号 to。✓ It is impossible to count every spider. ✗ for / of / that:此处用 to count。

### s5 seq9 | ans: estimated
被动“据估计” = it has been + 过去分词 estimated。✓ It has been estimated that… ✗ estimate / estimating / estimates:has been 后用过去分词。

### s5 seq10 | ans: that
定语从句,先行词 creatures 指动物,that 作从句主语。✓ the creatures that feed on insects. ✗ who(此处用 that)/ what / whose:指物/动物用 that。

### s5 seq11 | ans: who
定语从句,先行词 scientist 指人,who 作从句主语。✓ The scientist who made the census. ✗ which(指物)/ whom(作宾语)/ what:指人作主语用 who。

### s5 seq12 | ans: on
介词 + 关系代词:the crops on which we depend;depend on,故介词用 on。✓ the crops on which we depend. ✗ in / at / of:搭配 depend on。

### s5 seq13 | ans: nor
承接前面的否定“也不…”,nor + 部分倒装。✓ …, nor is it closely related to one. ✗ or / and / but:承接否定用 nor。

### s5 seq14 | ans: glance

### s5 seq15 | ans: content
