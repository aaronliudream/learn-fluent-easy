### u2.01 宾语从句(that / whether / if / what 等)
- Xie Lei said ____ she felt much more at home in the UK now.
  **that✓** / what / which / whether
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:said 后接陈述内容、从句完整不缺成分 → that(只连接不充当成分)。
- I don't know ____ the exchange student will come to our class.
  that / **whether✓** / what / which
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:表'是否'、句意未定 → whether(that 表确定陈述,此处不合)。
- Please tell me ____ you need before you go abroad.
  that / whether / **what✓** / if
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:tell me 后宾语从句缺 need 的宾语 → what(充当宾语;that 不作成分)。
- At first she had no idea about ____ she should say in class.
  that / which / if / **what✓**
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:介词 about 后从句缺 say 的宾语 → what;介词后不用 that/if。
- Her tutor explained ____ she must acknowledge other people's ideas.
  **that✓** / what / whether / how
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:explained 后陈述内容、从句完整 → that。
- The advisor asked ____ the students had any worries about going abroad.
  that / **whether✓** / what / which
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:asked 表'是否有'、未定 → whether(if 此处也行,但选项中只 whether 合且无 if)。
- Xie Lei was surprised at ____ the British people thought of Chinese culture.
  that / if / **what✓** / whether
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:介词 at 后从句缺 thought of 的宾语 → what;介词后不用 if/that。
- Leon couldn't believe ____ many kinds of Chinese food there are.
  that / which / whether / **how✓**
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:感叹'有多么多'、修饰 many → how;此处非'是否'也非缺名词成分。
- The host family told Xie Lei ____ they were keen to learn about China.
  **that✓** / what / if / which
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:told 后陈述内容、从句完整 → that。
- She wondered ____ she should stick to her own way or follow the local way.
  that / **whether✓** / what / how
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:wondered + 二选一'是否……还是' → whether(常与 or 连用;that 不表选择)。
- Studying abroad changed ____ Xie Lei thought about the wider world.
  that / if / **how✓** / whether
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:changed 后从句表'方式'、缺方式状语 → how(非'是否',非缺名词成分)。
- The interviewer asked the student ____ had impressed her most in China.
  that / if / whether / **what✓**
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:宾语从句缺主语 → what(充当主语;that 不作成分)。
- I think ____ getting involved in activities is the best way to fit in.
  **that✓** / what / whether / which
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:think 后陈述内容、从句完整 → that。
- Aisha was not sure ____ learning Chinese would help her future career.
  that / **whether✓** / what / how
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:be not sure 表'是否'、未定 → whether。
- Now she finally understood ____ her tutor had really wanted to say.
  that / if / **what✓** / whether
  考点:宾语从句(that / whether / if / what 等) ｜ 解析:understood 后从句缺 say 的宾语 → what。
