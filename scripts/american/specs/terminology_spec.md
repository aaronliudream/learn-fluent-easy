## 一、四条铁律

1. **教了再考**
   语法术语(主语/谓语/宾语/表语/系动词/助动词/情态动词/双宾/宾补/句型名称等)**首次**作为考点出现的课,关5 对应小节前必须有一张 **"语法小知识"折叠卡**(复用高中区渲染 `GrammarTipsView`;americans 存 `american_lessons.grammar_card` jsonb),用**本课课文句子**现场拆解,不堆抽象定义。
   **没有卡 → 不准出该术语的认知题。**

2. **认知题限量**
   贴标签/辨认类认知题(问"X 是什么动词 / 哪种句型")**每课 ≤3 道**。
   该结构其余题量用**用法题**覆盖:改写、补全、判断句子是否完整、介词选择、语序等——**考结构意识,不考名词背诵**。

3. **逐题解释兜底(④ 管线)**
   每道题 `payload.explanation_cn`:术语**首次出现必须现场翻译成白话并拆解本题句子**。
   例:"was 是 be 动词,funny 补充说明 The play——'谁 + 是 + 怎么样'就叫主系表。"
   做错也能学到东西。生成走 `build_perq.mjs`(或 am2 的 JSON explanation 字段)+ 三重校验(覆盖 / 答案词 / 防串味),**先导出全文 md 送审,复核过再落库**。

4. **配比决策(建每课考点清单时)**
   同步书列出的每个新术语,先判断"本册本课是否首次" → 首次则配"卡 + ≤3 认知题 + 若干用法题";非首次(前课已教)可不再上卡,认知题仍受 ≤3 限。

## 二、认知题 vs 用法题(判别)

| 类型 | 特征 | 例 | 每课上限 |
|------|------|----|---------|
| **认知题** | 问"这是什么"(贴术语标签/选句型名) | "can 是什么动词?" / "这句属于哪种句型?" | **≤3** |
| **用法题** | 问"怎么用对"(改写/补全/判断/选词/语序) | "换种说法:gave a seat ___ me(选 to)" / "哪句不完整,动词后缺宾语?" | 不限 |

用法题才是主力:它考的是**能不能造对句子**,而非能不能背出术语名。

## 三、折叠卡数据形态(GrammarTipsView / TipContent)

存 `american_lessons.grammar_card`(jsonb),字段:
```
{ title?, intro?, table?:{headers:[], rows:[[]]}, specialRules?:[{rule,mark?}], why?:[], examVsReal?:[{exam,real,note?}] }
```
- `table` 两列:成分/用法 → 本课例句(第二列渲染加粗)。
- `specialRules` 放判别法(如宾补"中间加 be 能成句")。
- 无 grammar_card 的课 → 关5 不渲染卡(纯加法,不挡做题)。

样板见 `docs/american/book2/am2_l01.json` 的 `grammar_card`(句子的骨架 · L1)。

## 四、元语法题(抽象概念辨认题)硬约束 · Aaron 2026-07-05 定,全库回扫

**定义**:题干形如"XX(时态/句型/词类)用来说什么/是什么/表示什么""下列哪个是…的定义""属于哪种句型/时态""规则动词过去式在词尾加什么"等——从抽象概念/规则里选定义、只考背诵、不考运用的题,叫**元语法题**(认知题里最空的一类)。
> 区分:`appreciate 的意思是` = **词义题**(合法保留);`一般过去时用来表示什么` = 元语法题(受本约束)。

**铁律(在"认知题 ≤3"之上再收窄)**:

1. **优先具体运用题**:凡能改成"真实例句里用对"的,一律改。
   例:`if 条件句用来说什么` → `If it ___ tomorrow, we'll stay home.(rain)` 选/填正确形式。
2. **每课元语法题 ≤1**:只在"本课有语法卡先教该概念"时,保留至多 1 道;其余全部换成运用题(题量不变、认知题总数仍 ≤3)。
3. **保留的那 1 道必须收窄到本课具体句型**:不出泛"条件句",出"第一类真实条件句";不出泛"过去时定义",挂本课句子。
4. **纯术语贴标签、无运用价值**(如"下列哪个是系动词")→ 删,用运用题补位。
5. **覆盖**:am1+am2 已产全部回扫(结论:am1 关5 零元语法题;am2 7 课超标已改);am3/am4 新课默认生效。
   扫描工具:`scripts/american/scan-metagrammar.mjs`(线上 DB) / `scan-metagrammar-local.mjs`(本地待跑 JSON)。
