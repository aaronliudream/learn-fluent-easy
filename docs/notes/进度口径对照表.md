# 进度百分比口径对照表

生成于 2026-07-26。四条线（小学 / 初中 / 高中 / 美语）的进度百分比**算法各不相同**。
本文档存在的唯一目的：**下次有人看到三条线数字不一致时，先来这里确认那是设计而非 bug，不要顺手"修"。**

> 调查方法：逐个打开实现文件读代码，非估算。文件路径与行号均为 2026-07-26 origin/main 实测。

---

## 一句话结论

**所有进度百分比都只读「关卡完成计数」，与「掌握度」是两套完全独立的数据源，没有任何计算上的关联。**

进度高不代表学会了；掌握度低也不会把进度拉下来。任何把进度条当学习效果指标的功能都会被误导 —— 见文末「⚠️ 进度与掌握天然脱钩」。

---

## 一、关卡 ✓ 是怎么打上的

三个 Hub（小学 / 初中 / 高中）机制相同：`completedStages: number[]` 存 localStorage（`savePersist`），
并经 `junior_hub_progress` 等表云同步；写入口是各自 `context.tsx` 的 `completeStage(unitId, stageIdx)`。

触发条件**因关型而异**（以初中 `JuniorHubStagePlay.tsx` 为例）：

| 关型 | 触发条件 | 位置 |
|---|---|---|
| 阅读 / 完形 / 听力 | **`tried >= 1` —— 做过 ≥1 篇/条就打 ✓，不看对错、不看分数** | :1349 / :1547 / :1685 |
| 其余关 | 关内流程走完 `handleFinish()` | :2085 |
| 从专区 play 页返回 | URL 带 `?done=1` 即标记 | :2090-2095 |

美语线不同：写 DB 表 `american_lesson_progress`，一行 = `(user_id, lesson_id, stage)`；
条件由各关自定（关 1 = 整篇播完 + 前置题答对；关 10 = 某轮全对；关 6/7 = 走完即算）。

## 二、四条线的百分比公式

| 线 | 数据源 | 单元% | 学期(册)% / 年级% | 是否排除未开放单元 |
|---|---|---|---|---|
| **小学** | localStorage `completedStages` + `stageProgress` | `Σ getStagePercent / 可完成关数`；**单关未完成也能贡献 0–99 的部分进度** | **`Σ 各单元percent / 单元数`（平均百分比）** | ✅ `isUnitListed`（= `available && published !== false`，**三条线里最严格**） |
| **初中** | localStorage `completedStages` | `完成关数 / 本单元关数` | `Σ完成关数 / Σ总关数`（计数） | ✅ 已与高中对齐（本次改动前不筛） |
| **高中** | localStorage `completedStages` | 同初中 | 同初中 | ✅ `filter(u => u.available)` |
| **美语** | DB `american_lesson_progress` | 每课环 = `已完成关数 / AMERICAN_STAGES.length` | 无册级百分比 | 不适用 |

### 三处刻意保留的差异

**① 小学用「平均百分比」，初中/高中用「关卡计数」。**
小学一个关做到一半能贡献 0–99；另两条线只有 0 或 100。
所以同样显示 "30%"，小学的含义是"平均每个单元完成三成"，初高中的含义是"三成的关卡已通关"。
**这是产品决策不是 bug**，等三条线内容都稳定后再定要不要统一（Aaron 2026-07-26 拍板挂账）。

**② 美语没有册级百分比**，只有每课 10 关的完成环。

**③ 关卡数**：美语固定 10 关（`AMERICAN_STAGES`，全局结构，非 per-lesson 数据）；
三个 Hub 的关数由各单元 `stages` 数组长度决定，单元之间可以不同。

## 三、掌握度是另一套，别混

| 板块 | 掌握度数据源 | 判定 |
|---|---|---|
| 初中词汇 | `junior_word_mastery` | 任一游戏 `consec >= 2` |
| 初中语法 | `junior_user_mastery` | 累计答对 2 次 |
| 听力/阅读/完形 | `mastery_progress` | 星级 |
| 高中 | `gaokao_user_mastery` | 各自 SRS |
| 美语 | `american_user_mastery` | SRS（`due_at` / `srs_step` / `lapses`） |

上表任何一张都**不参与**第二节的百分比计算，反之亦然。

---

## ⚠️ 进度与掌握天然脱钩

阅读 / 完形 / 听力关**做过 ≥1 篇就打 ✓，答错也算**（代码注释写明是刻意设计，非缺陷）。

推论，务必记住：

- 一个学生可以在**全部答错**的情况下把册进度刷到 100%。
- 因此**册进度不是学习效果指标**。任何新功能（家长报告、班级排名、AI 诊断输入、学习建议）
  若拿进度条当"学会了多少"，结论会系统性偏高。要衡量效果请读第三节那几张掌握度表。

Aaron 2026-07-26 拍板：**不改这个判定条件**，但必须在此显著记录。
