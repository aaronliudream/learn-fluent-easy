# Lesson 19  We're going to have a BBQ!

> 语法目标：be going to + 动词原形（计划打算） · Are you going to...? · It's going to be...

## 关5 · 语法专项

**① be going to + 动词原形（打算做某事）**

| 主语 | 例子 |
|---|---|
| I | **I'm going to grill** burgers. |
| he/she | **Lisa is going to make** potato salad. |
| we/they | **We're going to get** soda. |

**② 疑问与回答**：**Are you going to** come? — Yes, I am. / **What are you going to** do?

**③ It's going to be...（预测）**：It's going to be a great day!

**④ 时间表达**：this Saturday（本周六）/ this weekend（本周末）。

## 关5 · 语法专项

**① 否定祈使句：Don't + 动词原形**

| 例子 | 含义 |
|---|---|
| **Don't drop** it! | 别摔了！ |
| **Don't worry!** | 别担心！ |
| **Don't touch** the balloons. | 别碰气球。 |
| **Don't make** a sound! | 别出声！ |

**② 肯定祈使扩展**：Hurry!（快点）/ Move it up.（往上挪）/ Turn off the lights.（关灯）。

**④ 进行时复习**：I'm hanging the banner. / I'm carrying the cake.（一边做一边说）。

# Lesson 21  Is there any juice?
## 还有果汁吗？

> 语法目标：可数 vs 不可数名词 · 不可数名词 + some/any（There's some milk / Is there any juice?） · a lot of
> 场景：查冰箱列购物清单

## 关1 · 课文学习

**前置听力问题**：Listen and answer: Is there any juice in the fridge?
（a) Yes, there is.　b) No, there isn't. ✓　c) We don't know.）

| # | English | 中文 |
|---|---|---|
| 1 | AMY: Nate, I'm making a shopping list. Check the fridge. | 艾米：内特，我在列购物清单。你查下冰箱。 |
| 2 | NATE: On it! Okay... there's some milk. | 内特：这就去！嗯……有一些牛奶。 |
| 3 | AMY: Good. Is there any juice? | 艾米：好。有果汁吗？ |
| 4 | NATE: No, there isn't. And there isn't any cheese. | 内特：没有。奶酪也没了。 |
| 5 | AMY: Okay—juice and cheese. What about bread? | 艾米：好——记上果汁和奶酪。面包呢？ |

## 关5 · 语法专项

**① 可数 vs 不可数名词**

| 类型 | 特点 | 例子 |
|---|---|---|
| 可数 | 可加 -s，可用 a/an | egg → egg**s**, box, cookie |
| 不可数 | 不加 -s，不用 a/an | milk, juice, cheese, bread, water |

**② 不可数名词 + some/any（谓语用单数 is）**
- 肯定：There**'s some** milk.　疑问：**Is there any** juice?　否定：There **isn't any** cheese.

**③ 可数复数对照**：There **are some** egg**s**.（复数用 are）

**④ a lot of（很多，可数不可数通用）**：a lot of water / a lot of eggs。

| What about...? | 同（高频追问） | 那……呢？ |
