### s5 seq1 | ans: would have
与过去事实相反的虚拟语气,主句用 would + have + 过去分词。✓ the fact would have passed unnoticed. ✗ would(缺 have)/ will have(不用于过去虚拟)/ had:主句用 would have。

### s5 seq2 | ans: would
主句与过去相反用 would have + 过去分词;此处 have 已给出,填 would。✓ no one would have noticed. ✗ will / does / had:与过去相反的主句用 would。

### s5 seq3 | ans: had not
与过去相反,if 从句用 had + 过去分词,否定为 had not。✓ if fame had not come. ✗ did not / has not:过去虚拟条件用 had + 过去分词;✗ would not:if 从句里不用 would。

### s5 seq4 | ans: but
not only … but (also) …,“不但…而且”;连接词用 but。✓ not only change lives but even overthrow … ✗ and / or / nor:固定搭配是 not only … but。

### s5 seq5 | ans: but
not only … but also …;此处填 but,与后面 also 搭配。✓ not only informs us but also shapes our views. ✗ so / for / yet:与 not only 搭配的是 but。

### s5 seq6 | ans: did
not only 位于句首时,其分句要部分倒装,把助动词提到主语前;实义动词 become 用过去,助动词用 did。✓ Not only did the parents become famous … ✗ were(become 不用 be 助动)/ do(时态错)/ had(此处非完成时)。

### s5 seq7 | ans: that
同位语从句说明抽象名词 contention 的内容,引导词用 that(只起连接作用,不作成分)。✓ the contention that facts are sacred. ✗ which / what(要在从句中作成分)/ whether(表“是否”不合意)。

### s5 seq8 | ans: that

### s5 seq9 | ans: that

### s5 seq10 | ans: Acting

### s5 seq11 | ans: coming

### s5 seq12 | ans: bringing

### s5 seq13 | ans: was
