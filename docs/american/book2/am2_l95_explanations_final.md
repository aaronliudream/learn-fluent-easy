### s5 seq1 | ans: holds
每年惯例,用一般现在时。✓ Every fall, our town holds a harvest festival. ✗ is holding:进行,表此刻;✗ held:一般过去;✗ has held:现在完成。

### s5 seq2 | ans: have been helping
从过去一直帮忙到现在,用现在完成进行时 have been + doing。✓ I have been helping to plan it for two months. ✗ helped:一般过去;✗ help:一般现在;✗ am helping:现在进行,不强调“持续两个月”。

### s5 seq3 | ans: have never seen
“从未见过”,经验类,用现在完成时。✓ I have never seen the town so alive. ✗ never saw:缺 have;✗ am never seeing:进行;✗ had never seen:过去完成,与“说话此刻”不符。

### s5 seq4 | ans: were set up
过去“被搭起”,用一般过去被动 were + 过去分词。✓ Booths were set up near the square. ✗ set up:主动;✗ are set up:一般现在被动;✗ have set up:现在完成主动。

### s5 seq5 | ans: had been hung
“人群到之前早已被挂上”,用过去完成被动 had been + 过去分词。✓ Lights had been hung across the square. ✗ hung:一般过去主动;✗ are hung:一般现在被动;✗ have hung:现在完成主动。

### s5 seq6 | ans: were laughing
过去某时“正在笑”,用过去进行时 were + doing。✓ Children were laughing while musicians were playing. ✗ laughed:一般过去;✗ laugh:一般现在;✗ have laughed:现在完成。

### s5 seq7 | ans: rains
if 条件从句里用一般现在时表示将来。✓ If it rains, the whole event will be moved indoors. ✗ will rain:从句里不用 will;✗ is raining:进行;✗ rained:一般过去。

### s5 seq8 | ans: will be
对将来的判断,用一般将来时。✓ Next year's festival will be even bigger. ✗ is:一般现在;✗ was:过去;✗ has been:现在完成。

### s5 seq9 | ans: will be moved
将来“被挪到室内”,用将来被动 will be + 过去分词。✓ If it rains, the event will be moved indoors. ✗ will move:将来主动;✗ is moved:一般现在被动;✗ moved:一般过去。

### s5 seq10 | ans: is being served
