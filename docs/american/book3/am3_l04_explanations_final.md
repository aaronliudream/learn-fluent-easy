# AM3 L04 逐题解释(定稿·原创承载·现在完成时 vs 现在完成进行时 + 动词+to sb + worth) · 供 gen-book3-seed.mjs loadExp 合并

### s5 seq1 | ans: has
“到现在都没发现过”是讲到现在为止的结果,用现在完成时 has + 过去分词(found);主语 wife 是第三人称单数,配 has。✓ His wife has never found out. ✗ is / was / does:配不出现在完成时。

### s5 seq2 | ans: has
“刚刚找了新工作”强调刚完成,用现在完成时 has + taken;主语 Danny 单数配 has。✓ Danny has just taken a new job. ✗ is / was / will:配不出“刚刚完成”的现在完成时。

### s5 seq3 | ans: have
“到现在为止一直替他保密”讲到现在的结果,用现在完成时;主语 workers 是复数,配 have。✓ His fellow workers have kept his secret. ✗ has:那是单数用的;✗ are / were:配不出现在完成时。

### s5 seq4 | ans: heard
have never + 过去分词表示“从没……过”的经历;hear 的过去分词是 heard。✓ I have never heard such a story. ✗ hear / hearing / hears:都不是过去分词,配不出现在完成时。

### s5 seq5 | ans: has been working
“当清运工干了两年、一直干到现在”强调动作从过去持续到现在,用现在完成进行时 has been + doing。✓ Danny has been working for two years now. ✗ works / worked / is working:都表达不出“持续了两年到现在”。

### s5 seq6 | ans: has been raining

### s5 seq7 | ans: have been waiting

### s5 seq8 | ans: have cleaned
“到目前为止扫了三条街”强调完成的数量、结果,用现在完成时 have + 过去分词。✓ The workers have cleaned three streets so far. ✗ have been cleaning:那更强调“一直在扫”的过程,这里落点在“扫了几条”的结果;✗ clean / cleaned:配不出现在完成时。

### s5 seq9 | ans: have been working

### s5 seq10 | ans: have read
